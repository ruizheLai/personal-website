# Typography study

The lab serves Latin WOFF2 files locally. Each file has the corresponding SIL Open Font License 1.1 notice from the Google Fonts upstream repository in the same directory. This package allows web embedding and redistributing the original binaries with their notices. The loaded type system is isolated to lab pages.

| Concept | Display | Body and navigation | Technical detail |
| --- | --- | --- | --- |
| A | Bricolage Grotesque 500, close tracking and stacked lines | Manrope 400–700, compact and open at small sizes | IBM Plex Mono 400 for a few short labels |
| B | Space Grotesk 500–600 with pronounced scale changes | Instrument Sans 400–700 | DM Mono 400 |
| C | Instrument Serif 400 for the signature and exhibit headings | Geist 400–700 | Geist 400, so notes remain readable on the warm canvas |

A evaluates the character sought from Cabinet Grotesk and General Sans with open-source substitutes. The chosen binaries have verified redistributable notices alongside them. No Fontshare files are included. B implements the requested pairing. C uses the contrast between the narrow serif and the firm sans as the main source of personality.

The live comparison uses identical headline and body specimens. The concepts then show the letterforms in actual context, where line length and grid width change the result. A uses “Ideas made tangible.” with “Product design · Interaction · AI.” B uses “Design in motion.” The C signature makes the designer's own name the text object.

Recommend A's display and body combination, keeping mono for context labels only. Before production, compare the wordmark at 320–400 px, test long project names, and confirm font subsets when additional languages are in scope.
