# Sketch annotation font

`caveat-annotation.ttf` is a self-hosted, 11,040-byte subset of Caveat Regular used only for “early explorations”.

- [Official source](https://github.com/google/fonts/tree/main/ofl/caveat)
- [Subset request](https://fonts.googleapis.com/css2?family=Caveat:wght@400&text=early%20explorations&display=swap)
- License: SIL Open Font License 1.1; retain `Caveat-OFL.txt` with the font.

The browser does not contact Google. If the annotation text changes, regenerate a subset containing the new glyphs. The main site sans-serif remains unchanged.
